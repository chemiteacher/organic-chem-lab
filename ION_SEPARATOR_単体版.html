① 系統分離の王道5ステップ

  • 第1属 (Ag⁺, Pb²⁺)：希 HCl で白沈 → 加熱で PbCl₂ のみ溶解
  • 第2属 (Cu²⁺, Pb²⁺ 等)：酸性＋H₂S で黒沈 (CuS, PbS)
  • 第3属 (Fe³⁺, Al³⁺)：過剰 NH₃ でゲル沈殿（Mg²⁺混在時は先に NH₄Cl！）
  • 第4属 (Zn²⁺, Fe²⁺)：塩基性＋H₂S で ZnS(白)・FeS(黒)
  • 第5属 (Ba²⁺, Ca²⁺)：希 H₂SO₄ や 酢酸酸性＋K₂CrO₄

② 「少量 → 過剰」で再溶解するイオン

  • 過剰 NaOH（両性元素：ああすんなり）
    Al³⁺・Zn²⁺・Sn²⁺・Pb²⁺・Cr³⁺ が無色（Crは緑）に再溶解！
  • 過剰 NH₃水（錯イオン）
    Cu²⁺ → 深青色 [Cu(NH₃)₄]²⁺
    Zn²⁺・Ag⁺・AgCl → 無色透明に溶解！
  • CO₂ 通気：[Al(OH)₄]⁻ から Al(OH)₃ が白沈再生成！

③ 入試頻出の沈殿・呈色カラー

AgCl・BaSO₄・Al(OH)₃・ZnS（白） CuS・PbS・Ag₂S・FeS（黒） Fe(OH)₃・Ag₂CrO₄（赤褐） Cu(OH)₂（青白） [Cu(NH₃)₄]²⁺（深青） PbCrO₄・BaCrO₄・CdS・AgI（黄） Fe³⁺＋KSCN（血赤色）

④ 炎色反応＆鉄イオン識別

  • 炎色反応：Na⁺(黄) / K⁺(赤紫) / Ca²⁺(橙赤) / Ba²⁺(黄緑) / Cu²⁺(青緑)
  • Fe³⁺ の確認：KSCN → 血赤色 / K₄[Fe(CN)₆] → 濃青色沈殿
  • Fe²⁺ の確認：K₃[Fe(CN)₆] → 濃青色沈殿（KSCNでは無変化）
